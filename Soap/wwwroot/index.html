Import a collection

Collect your reposts from TikTok Setup guide

The bookmarklet collects video links while you browse TikTok. It copies them to your clipboard so you can import them here.

  1. Make sure your bookmarks bar is visible (Chrome/Firefox: Ctrl+Shift+B).
  2. Drag this button onto it: 📥 Soap reposts
  3. Go to your TikTok reposts page: tiktok.com/@yourname → click the Reposts tab.
  4. Click the Soap reposts bookmark. It auto-scrolls, then copies all video URLs to your clipboard.
  5. Return here, paste (Ctrl+V) into Import a collection, then choose Import videos.

Start on your Reposts tab. The bookmarklet collects from the top down so newer reposts appear first in your library.

TikTok cookies …

Some videos need a TikTok login to download. Add your session cookies here if a download asks you to sign in.

  1. Log into tiktok.com in your browser.
  2. Press F12 → Network tab → reload the page if the list is empty.
  3. Click any request to tiktok.com → scroll the right panel to Request Headers.
  4. Copy the line that starts with Cookie: (or just the value after it).
  5. Paste it below and click Save.
Download speed …

A short break between videos helps avoid TikTok rate limits. The default is 2.5–5.5 seconds. Increase the delay if downloads are being blocked.
